# UI preview

Generated by running the real handlers against a fake Telegram client and
the real chat store, then stripping the HTML the client would send. The
data is example data, the layout is exactly what the bot produces.

Tables are monospace text inside `<pre>` here because a preview cannot
send to Telegram; when a rich message goes through, a panel is a real
`<h2>` over a real `<table>` (Bot API 10.3), and `agent.utils.rich`
degrades to this grid if Telegram refuses one. Screens that are
*edited* — `/menu`, the `/help` sections, the plugin panel — always
use the grid, because Telegram has no `edit_rich_message`.
